# crd-bot — แพ็กเกจทดลองสำหรับทีม

ดาวน์โหลดแล้วรันตัวติดตั้งเพื่อสร้างระบบ crd-bot แยกบน Windows 11 ของแต่ละคนครับ แพ็กเกจสร้าง **neo และ swift อัตโนมัติ** พร้อมกติกาส่งงานระหว่างบอท, icon หุ่นยนต์แมว, หน้าเว็บชื่อ crd-bot, ฟอนต์ไทย และเครื่องมือค้น/อ่านข่าวครับ

**สถานะ: รุ่นทดลองที่ผ่านการทดสอบระบบแยกบน WSL เครื่องต้นแบบแล้วครับ** ยังไม่รับรองการติดตั้งบน Windows เครื่องอื่นจนกว่าจะทำ checklist ด้านล่างครบครับ [ผลทดสอบ](rakazo/team-installer/tests/validation.txt) ระบุทั้งสิ่งที่ผ่านและสิ่งที่ยังไม่ได้ทดสอบครับ

## ดาวน์โหลด

[ดาวน์โหลด ZIP ของชุดทดลอง](https://github.com/BoomWarapant/ai-agent/archive/refs/tags/crd-bot-team-2026.10.29-rc1.zip) แล้วแตกไฟล์ทั้งหมดไว้ในโฟลเดอร์ถาวร เช่น `C:\crd-bot` ครับ อย่ารันจากภายใน ZIP ครับ

หรือใช้ Git ครับ

```powershell
git clone --branch feat/research-bots --single-branch https://github.com/BoomWarapant/ai-agent.git
```

ให้ใช้ branch `feat/research-bots` สำหรับรุ่นนี้ครับ `main` ยังไม่ได้รวมแพ็กเกจนี้ครับ

## เตรียมเครื่องครั้งแรก

1. ใช้ Windows 11 และ Microsoft Edge พร้อมอินเทอร์เน็ตสำหรับดาวน์โหลด Docker images และเชื่อมโมเดลครับ ต้องมีพื้นที่ว่างสำหรับ images หลาย GB และข้อมูลบอทเพิ่มเติมครับ
2. เปิด PowerShell แบบ Administrator แล้วตรวจ WSL ครับ

```powershell
wsl --list --verbose
```

3. ถ้ายังไม่มี `Ubuntu-24.04` ให้ติดตั้งด้วยคำสั่งนี้ ทำตามข้อความบนจอและ restart หากระบบร้องขอ แล้วเปิด Ubuntu เพื่อสร้างผู้ใช้ให้เสร็จครับ

```powershell
wsl --install -d Ubuntu-24.04
```

4. ต้องใช้ WSL2 และ systemd ครับ ถ้ามี Docker Desktop หรือ Docker เดิม ให้ผู้ดูแลตรวจระบบก่อน เพราะชุดนี้ใช้ Docker Engine ภายใน Ubuntu โดยตรงครับ

คำสั่งติดตั้งด้านล่างติดตั้ง Docker หากยังไม่มี สร้าง Linux user `rakazo` และ build images จาก upstream ที่ล็อก digest ไว้ครับ การ build ครั้งแรกใช้เวลาตามความเร็วเครือข่ายและเครื่องครับ

## ติดตั้ง

เปิด PowerShell ปกติในโฟลเดอร์ที่แตกไฟล์ ซึ่งต้องมองเห็น `Install-crd-bot.ps1` ครับ

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\Install-crd-bot.ps1"
```

ตัวติดตั้งจะตรวจ checksum ก่อนทำงาน สร้างค่าระบบสุ่มใหม่ ติดตั้ง services และสร้าง Shortcut **crd-bot-team** พร้อม icon neo บน Desktop ครับ การใช้ `ExecutionPolicy Bypass` ในคำสั่งนี้มีผลเฉพาะ process ที่เรียกครับ

เมื่อเปิดแอปครั้งแรก ให้ทำสองอย่างนี้ครับ

1. **สมัครบัญชีของตนเอง** ครับ ระบบจะสร้าง neo/swift พร้อม ID ของเครื่องนั้น และตั้งการส่งงานหากันโดยอัตโนมัติครับ ไม่ต้องคัดลอก ID จากเครื่องต้นแบบครับ
2. **เชื่อมโมเดลของตนเอง** ในหน้าตั้งค่า provider/model ของแอป แล้วเลือกโมเดลที่บัญชีใช้งานได้ครับ แพ็กเกจไม่พ่วงบัญชีสมาชิก API key หรือโควตาโมเดลครับ ค่าใช้จ่ายขึ้นอยู่กับ provider และบัญชีของผู้ทดลองครับ

ถ้ามีบริการใช้ port 5173 หรือ 3100 อยู่แล้ว ตัวติดตั้งจะหยุดครับ สำหรับเครื่องที่ต้องการใช้ port อื่น ให้กำหนดทั้งสองค่าครับ

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\Install-crd-bot.ps1" -WebPort 5273 -ApiPort 3200
```

หากการ build หรือเริ่มบริการล้มเหลวระหว่างติดตั้ง ให้แก้เหตุที่แสดงแล้วรันคำสั่งเดิมซ้ำครับ ตัวติดตั้งจะใช้ค่าระบบที่สร้างไว้ ไม่สุ่มรหัสใหม่ทับข้อมูลเดิมครับ เมื่อติดตั้งสำเร็จแล้วให้ใช้ Shortcut หรือ `Start-crd-bot.ps1` เพื่อเปิดครั้งถัดไปครับ

## สิ่งที่ได้

| ส่วน | พฤติกรรม |
|---|---|
| neo | ผู้ประสานงานหลัก ส่งงานค้นข้อมูลให้ swift และสรุปผลครับ |
| swift | ค้นข่าวได้สูงสุด 4 คำค้น/8 ครั้งอ่าน เปลี่ยนแหล่งเมื่อเว็บปฏิเสธ และตรวจวันเผยแพร่จริงครับ |
| icon | neo เป็นแมวหุ่นยนต์หมวกวิศวกร และ swift เป็นแมวหุ่นยนต์ใส่ headset ครับ Shortcut และ favicon ใช้ neo ครับ |
| บัญชีใหม่ | แต่ละบัญชีได้คู่บอทของตนเอง มี thread และ computer แยกครับ การ login ซ้ำไม่สร้างคู่บอทซ้ำหรือทับกติกาที่แก้เองครับ |
| เครื่องมือ | web_search/web_fetch, การแนบไฟล์ Office และฟอนต์ไทยใน computer image ครับ |

Memory Hub, Google Drive, skill ภายใน CRD และเอกสารโครงการ **ไม่รวมอยู่ในแพ็กเกจ public** ครับ ต้องติดตั้ง/เชื่อมแยกด้วยสิทธิ์ของผู้ทดลองครับ ตัวติดตั้งไม่คัดลอกประวัติแชต ฐานข้อมูล หรือ credentials จากเครื่องต้นแบบครับ

## Checklist บนเครื่องใหม่ก่อนแจกทีม

- [ ] ติดตั้งจาก ZIP สำเร็จโดยไม่มี error ครับ
- [ ] เปิด Shortcut crd-bot-team แล้วเห็น icon neo และหน้าเว็บ crd-bot ครับ
- [ ] สมัครบัญชีแล้วเห็น neo/swift ทั้งสองตัว พร้อม avatar ต่างบทบาทครับ
- [ ] เชื่อมโมเดลและสั่ง neo แนะนำตัว แล้วเห็นคำตอบในแชตครับ
- [ ] ส่งคำขอด้านล่างแล้วเห็น neo ส่งงานให้ swift และได้รับสรุปกลับในหน้าต่างครับ
- [ ] ข่าวครบ 3 URL บทความ พร้อมวันที่เผยแพร่ที่ตรวจจากเนื้อหาหรือ datePublished ครับ หากเว็บปฏิเสธต้องเปลี่ยนแหล่งหรือรายงานข้อจำกัดจริงครับ
- [ ] ปิดหน้าต่างแล้วเปิดใหม่ ประวัติยังอยู่และส่งข้อความใหม่ได้ครับ
- [ ] login ซ้ำแล้วบอทไม่เพิ่มซ้ำ และกติกาที่แก้เองยังอยู่ครับ

```text
ช่วยค้นข่าว AI ล่าสุดที่สำคัญ 3 เรื่อง โดยค้นเว็บใหม่และเปิดอ่านบทความจริง
พร้อมสรุปสั้น ๆ วันที่เผยแพร่ และลิงก์ต้นทางของแต่ละเรื่องครับ
ถ้าเว็บปฏิเสธให้เปลี่ยนแหล่ง ถ้ายืนยันไม่ครบให้แจ้งจำนวนที่ยืนยันได้จริงครับ
```

การทดสอบระบบแยกรอบนี้ผ่าน signup/provisioning, การแยกบัญชี, การเก็บกติกาที่แก้เอง, web adapter 8 tests และ avatar 2 tests ครับ ยังไม่ได้เชื่อมบัญชีโมเดลบนระบบทดสอบใหม่ จึงต้องทำข้อทดสอบแชตจริงบนเครื่องผู้ทดลองต่อครับ

## เปิดครั้งถัดไปและดูแลข้อมูล

ใช้ Shortcut **crd-bot-team** หรือรันคำสั่งนี้จากโฟลเดอร์เดิมครับ

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\Start-crd-bot.ps1"
```

หากติดตั้งด้วย port อื่น ให้ส่ง `-WebPort` ค่าเดียวกับตอนติดตั้งครับ อย่าย้ายหรือลบโฟลเดอร์สคริปต์ เพราะ Shortcut ชี้มาที่ไฟล์นี้ครับ

ระบบอยู่ใน WSL ที่ `/home/rakazo/crd-bot-team` ใช้ Docker Compose project `crd-bot-team` และ volumes ของ project นี้ครับ อย่าลบ volumes หรือไฟล์ `.env` เพราะเกี่ยวข้องกับข้อมูลและการถอดรหัส credentials ครับ แพ็กเกจนี้เป็นการติดตั้งใหม่ ไม่ใช่เครื่องมือย้ายข้อมูลจากระบบเดิมครับ

## เมื่อมีปัญหา

| อาการ | วิธีตรวจ |
|---|---|
| ไม่มี Ubuntu หรือ systemd | ตรวจขั้นเตรียมเครื่อง แล้วเปิด Ubuntu ให้ติดตั้งครั้งแรกเสร็จครับ |
| checksum ไม่ผ่าน | ดาวน์โหลด ZIP ใหม่ทั้งชุด อย่าแก้ข้ามการตรวจ checksum ครับ |
| port ถูกใช้ | ปิดบริการที่ไม่ใช้ หรือเลือก port อื่นตามตัวอย่างครับ |
| build/download ไม่ผ่าน | ตรวจอินเทอร์เน็ตและพื้นที่ แล้วรันติดตั้งซ้ำด้วยค่าเดิมครับ |
| แชตไม่ตอบ | ตรวจว่าบัญชีโมเดลเชื่อมสำเร็จและยังมีสิทธิ์/โควตาครับ |
| คำตอบค้างบนหน้าจอ | ลอง Ctrl+R หนึ่งครั้ง ตรวจคำตอบล่าสุดก่อนส่งซ้ำ และแจ้งผู้ดูแลหากเกิดซ้ำครับ |
| ต้องการ Memory Hub/Drive/skill ภายใน | ให้ผู้ดูแลเชื่อมแยก ไม่ใช้ token ของเครื่องต้นแบบครับ |

ส่งผู้ดูแลเฉพาะเวลาเกิดเหตุ รุ่นของชุดที่ดาวน์โหลด และข้อความ error ที่ปิดข้อมูลลับแล้วครับ ดู [เครดิตแพ็กเกจ](rakazo/team-installer/NOTICE.txt), [license upstream](rakazo/team-installer/LICENSE.upstream) และ [เอกสารระบบเดิม](rakazo/docs/OPERATIONS.md) ประกอบได้ครับ คำสั่งระบบเดิมอาจใช้ project/path ต่างจากแพ็กเกจทีม ต้องปรับให้ตรงก่อนใช้ครับ
